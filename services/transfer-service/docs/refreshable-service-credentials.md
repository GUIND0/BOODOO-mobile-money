### Refreshable service credentials
Set `TRANSFER_OAUTH_CLIENTS_JSON` to a secret-managed tenant map: `{"partner-a":{"tokenEndpoint":"https://issuer.example/oauth/token","clientId":"...","clientSecret":"...","scope":"space separated least privilege grants","audiences":["boodoo-transfer-api","boodoo-ledger-api"]}}`. Configure all dependency audiences/scopes needed for the workflow, including `ledger:post:transfer`, `ledger:controls:read` and `ledger:journals:cancel` after the respective feature PRs. The trusted issuer must bind integrator_id, actor_type=service and sub=transfer-service. Client credentials use HTTP Basic, HTTPS, no redirects, 64 KiB response cap and a total five-second wait. Tokens are cryptographically validated and cached only until 30 seconds before expiry; configured OAuth failures never fall back to static credentials. Static token JSON remains a local development adapter for tenants without OAuth entries. No OAuth server or end-user OTP is implemented here.

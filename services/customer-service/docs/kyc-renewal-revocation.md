### Renew or revoke KYC
Operator POST `/internal/v1/customers/{id}/kyc-lifecycle` with `kyc:lifecycle` and body `{"id":"event UUID","action":"REVOKE","expectedVersion":3,"reasonCode":"EVIDENCE_WITHDRAWN"}`. RENEW and REVOKE invalidate an APPROVED or UNDER_REVIEW dossier, increment profile version and return PENDING so the integrating app can update and resubmit evidence. All previous dossiers/decisions remain immutable. Current approval immediately becomes false; wallet authorization checks consume that fact. Event IDs are bound to the original actor and input. In-flight posting already authorized before revocation requires an explicit accounting freeze for a hard barrier; call wallet control when an immediate financial hold is required.
